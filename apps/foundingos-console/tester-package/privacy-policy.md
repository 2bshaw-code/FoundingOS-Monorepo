## What we collect

- Your email address (as entered at sign-in).
- Your access code (password), and which module/survey it is associated
  with.
- The answers you submit in your assigned survey.

## What we do NOT collect

- Government ID numbers.
- Financial account details or payment information.
- Any sensitive personal data (health, biometric, etc.).

## How it's stored

Locally, on the server running this evaluation instance, in a JSON file —
not shared with any third party or external service. See
`legal-acceptance-store.server.ts` for the acceptance-log mechanism
specifically.

## How it's used

Solely to run the testing/evaluation program and to improve the System.

## Retention

For the duration of the testing program. Data is not automatically deleted
afterward unless a deletion request is made (see below).

## Deletion requests

Contact the program administrator to request removal of your submitted data.

## GDPR / UK-GDPR notes (non-certifying)

This program is designed with data minimization as a default — see
`compliance-notes.md`. Whether this specific deployment is fully compliant
with GDPR/UK-GDPR is a legal determination for the Legal Reviewer to confirm,
not something this document certifies on its own.
